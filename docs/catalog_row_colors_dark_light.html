Catalog row colors — dark & light (v6.2.24)

Shipped semantics: amber = update available, green = verified up to date, red = crash-related culprit, blue = row selection (not a status). Light-mode values below are proposals for a future Day theme — not implemented in the app yet.

Row states Selection stacking Drivers tab Firmware tab Dark → light map
Rules (both themes, same logic):
• tier == culprit → red row tint + red device name
• status == newer or tier == outdated → amber row tint + gold device name
• status == same → green row tint; status text green
• Click selection → blue overlay (#1e4a7a night / #bfdbfe day) on top of status tint
• Icon + Include columns stay neutral (no status tint)
