Two-tone checkbox mockup (preview only)

Proposal: when checked, the box uses a lighter theme tint for the fill and border, and the checkmark uses the strong accent (same hue family, two tones). Unchecked stays neutral (card alt + border). This is a visual spec only — not wired into the app yet.

Shipped in app (gui_theme.py): CHECKBOX_FILL, CHECKBOX_BORDER, CHECKBOX_CHECKMARK per theme preset; resolve_checkbox_tokens() supplies fallbacks for new themes.
