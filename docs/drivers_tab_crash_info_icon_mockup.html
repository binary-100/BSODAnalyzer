Option D — Info icon on crash-linked rows

Blue ⓘ at the end of the Device column (crash-linked rows only). Hover or click the icon for why this row is highlighted. Non-crash rows have no icon — zero clutter.

Design notes

  • Icon only on _crash_linked rows — not every device.
  • Uses accent blue (same as links), not red — explains red without competing with it.
  • Tooltip: module name, BugCheck, match reason (WinDbg / inventory).
  • Reuses Qt QToolTip or custom popup; no banner space needed.
  • Works with All devices view; Needs attention filter optional.

Hover the ⓘ on the NVIDIA row to see the tooltip.
