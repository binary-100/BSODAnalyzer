Driver: storahci.sys — Moderate severity

Most recent crash points to storage stack; check Samsung NVMe firmware and chipset drivers.

SummaryAction PlanCrash Details SystemDriversFirmwareAdvanced
What happened (in plain English)

Windows bug-checked with stop code 0x0000007A (KERNEL_DATA_INPAGE_ERROR). The faulting module reported in the dump was storahci.sys.

Likely cause

Storage driver / disk I/O path — often NVMe driver, cable/seat, or firmware. Your Samsung 990 PRO is on driver stack; firmware tab shows revision 8B2QJXD7.

What to do first

  • Run Samsung Magician or check Firmware tab for SSD update
  • Search Drivers tab for chipset / storage filter updates
  • Confirm NVMe driver isn't generic Microsoft only

Step 2 — Update storage / chipset drivers

Open Drivers tab → Load devices → Search. Prioritize Samsung NVMe controller, AMD chipset, storahci-related packages.

Enable kernel memory dump if crashes continue — Advanced tab / Enable Memory Dump.

After changes, monitor Reliability Monitor for 48–72 hours before closing the case.
