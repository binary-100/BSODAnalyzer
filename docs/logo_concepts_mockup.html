BSOD Analyzer — Logo / Icon Concepts

Five starter directions for exe icon, window title bar, and About dialog. Matches Night theme accent #2f81f7. Avoid literal Windows BSOD screen copies.

Trust · protection · “we fix crashes”

Strong default for a support tool. Reads well at 16×16 if simplified to shield + “!” only.

B — Severity Pulse

Ties to in-app severity meter

Instantly connects to Summary tab UX. Unique among generic “bug” icons.
