Why they’re separate Design intent

Checkbox = yes/no on an option (Include, backup before install, delete dumps).

Menu checkmark = which theme is active (one of many, shown in a menu).

Radio = pick exactly one mode (portable vs full install).

Tool button = show/hide a panel (Details expander).

If you want menu ticks or radios to visually match the two-tone square style, that would be a separate polish pass — different Qt APIs than QCheckBox.
