Unified catalog row colors — dark mode (v6.2.24)

Drivers and Firmware share one rule set via _apply_catalog_row_style. Amber = update available; green = verified up to date; red = crash-related culprit tier.

Selected row (Qt highlight — blue) Update available — amber tint Up to date — green tint Crash-related — red tint Default / not checked yet
Rules (both tabs):
• tier == culprit → red background #3a2228, red name text
• status == newer OR tier == outdated → amber background #3a3420, gold name text
• status == same → green tint rgba(63,185,80,.14)
• Status column: gold “Update”, green “Up to date”, muted “No match”, blue “Checking…”
• Icon + Include columns: always neutral (no tint)
